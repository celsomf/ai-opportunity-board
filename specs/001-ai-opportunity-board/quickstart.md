# Quickstart Guide: AI Opportunity Board

This guide explains how to spin up the project and verify it.

## Installation
Ensure you have Node.js installed. Then run:
```bash
npm install
```

## Running the App in Development Mode
Start the Vite development server:
```bash
npm run dev
```
Open the printed URL (usually `http://localhost:5173`) in your browser.

## Running Tests
Run Vitest to verify logic, score calculations, and validation rules:
```bash
npm test
```

## Production Build
Build the static files for production deployment:
```bash
npm run build
```
The output files will be located in the `dist/` directory.
